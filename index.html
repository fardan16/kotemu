Penerapan Siklus SDLC Waterfall & Web GIS

Aplikasi KoTemu dikembangkan menggunakan pendekatan SDLC Model Waterfall (Siklus Hidup Pengembangan Perangkat Lunak) dan memenuhi 3 unsur spasial Sistem Informasi Geografis (Point, Line, Polygon) berbasis Citra Satelit Resolusi Tinggi:

1. Analisis Kebutuhan (Requirements Analysis)

Mengidentifikasi kebutuhan pengguna dalam mencari kafe di Kota Palu, mendata 30 titik koordinat lapangan, foto observasi, dan kebutuhan atribut spasial (kategori, fasilitas, harga, jam buka).

2. Perancangan Sistem (System & Database Design)

Merancang arsitektur Web GIS terpusat dengan basis data Firebase Cloud Firestore, memetakan 3 unsur spasial: Point (30 kafe), Line (jaringan jalan arteri akses), dan Polygon (batas wilayah resmi Kota Palu di atas citra satelit).

3. Implementasi (Implementation & Coding)

Membangun antarmuka interaktif menggunakan HTML5, modern CSS3 Coffee Theme, engine peta Leaflet.js dengan peta dasar citra satelit, integrasi SDK Firebase Firestore, dan OSRM Routing Machine untuk kalkulasi rute navigasi turn-by-turn.

4. Pengujian (Testing & Verification)

Memvalidasi keakuratan 30 titik koordinat GPS di atas citra satelit Kota Palu, pengujian fungsionalitas pencarian, filter, respon klik popup peta, perhitungan rute, dan sinkronisasi data database.

5. Penerapan & Pemeliharaan (Deployment & Cloud Sync)

Aplikasi telah berhasil dideploy secara live ke internet dengan protokol HTTPS terenkripsi serta siap disinkronisasi ke Firebase Hosting.

📍 Struktur Data Spasial Peta Satelit Kota Palu yang Diterapkan:
  • Peta Dasar: Citra Satelit Resolusi Tinggi (Esri World Imagery & Google Hybrid).
  • Batas Wilayah Kota Palu: Poligon resmi batas administratif Kota Palu (395,06 km²).
  • Line (Garis): Jaringan Jalan Arteri Akses (Jl. Juanda, Jl. Monginsidi, Jl. Gajah Mada, Jl. Samrat, dll).
  • Point (Titik): 30 Titik Koordinat Kafe Lapangan Bab 3.

Masukkan / Hubungkan Konfigurasi API Firebase Anda:

Tempel kode konfigurasi dari Firebase Console di bawah (bisa berupa teks JavaScript const firebaseConfig = { ... } atau JSON murni):

Panduan 5 Langkah Cara Mengambil API Firebase dari Konsol:
1
Buka Konsol Firebase:

Kunjungi console.firebase.google.com dan masuk menggunakan akun Google Anda.

2
Buat Proyek Baru:

Klik "Tambahkan proyek" (Add project) • Beri nama proyek: KoTemu • Lanjutkan hingga proyek berhasil dibuat.

3
Daftarkan Aplikasi Web & Salin API:

Di halaman Project Overview, klik ikon Web (</>) • Masukkan nama aplikasi KoTemu-Web • Klik Daftarkan aplikasi • Firebase akan menampilkan blok const firebaseConfig = { ... }. Salin seluruh kode tersebut!

4
Aktifkan Firestore Database & Rules:

Di bilah menu kiri, klik Firestore Database • Klik Create Database • Pilih lokasi server (contoh: asia-southeast2 Jakarta) • Buka tab Rules dan ganti menjadi: allow read, write: if true; • Klik Publish.

5
Tempelkan ke Aplikasi:

Kembali ke tab Status & Hubungkan API di modal ini, tempelkan kode yang Anda salin ke kolom input, lalu klik Hubungkan & Simpan API. Selesai!

🚀 Cara Mengambil Link / URL Halaman dari Firebase Hosting:

Jika Anda ingin halaman website ini terdeploy langsung di domain resmi Firebase (misal: https://kotemu-palu.web.app), jalankan 3 langkah ini di Terminal:

# 1. Buka folder proyek di Terminal
cd program

# 2. Login ke akun Google Firebase Anda
firebase login

# 3. Deploy langsung ke Firebase Hosting
firebase deploy

Setelah perintah selesai, terminal Firebase CLI akan langsung memberikan tautan hosting resmi halaman Anda:
Hosting URL: https://<id-proyek-anda>.web.app
